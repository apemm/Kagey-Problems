# Predictions for the second round, written before the runs (2026-10-25)

Q1 (M1 for a fresh minus start at the plus end). With kappa = u 1{j>=1}, for
j >= 1:
N (R_N(j+1) - R_N(j)) = N Delta u(j) + Psi_-(j) + o(1),
Psi_-(j) = alpha_+ [ (j+1) Delta u(j) + 2 mu_+ Delta v(j) + 2 u(j)
                     - 2 mu_+ Delta u(j) ],
while for a fresh plus start Psi_+(j) = Delta C(j) = alpha_+ [ (j+1) Delta u(j)
+ 2 mu_+ Delta v(j) + 2 u(j) ]. Prediction: for the zeta law, alpha = 1.5,
the discrepancy for the minus start is of the same size as for the plus start
(about 34 j/N), and it shrinks like 1/N at fixed j.

Q2 (fair start). The discrepancy against (Psi_+ + Psi_-)/2 behaves the same.

Q3 (every N, completely monotone laws). For mixtures of two or three
geometric laws (completely monotone, exponential tails), the number of sign
changes of Delta P_N stays <= 5 for all N <= 300 with a fair start.
I have no strong prior here; a violation would show that the total
positivity route cannot give "at most three modes for every N" for all
completely monotone laws without a tail condition.
