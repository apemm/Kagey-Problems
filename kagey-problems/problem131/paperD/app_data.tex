\section{Data and certificate records}\label{app:data}

The \href{https://github.com/apemm/Kagey-Problems/tree/paperD-ejp-v3/kagey-problems/problem131/paperD}{tagged repository}
and submission archive contain the certificate code, records, source
hashes and rerun commands. The parameter-cover records are
\nolinkurl{data/threshold_*.txt}, checked by
\nolinkurl{certify_threshold.py}. The transition derivative records
use $1100$ moments at $1600$ bits, Python~3.12.14 and
python-flint~0.8.0.

With python-flint~0.9.0, \nolinkurl{check_critical_shape.py} checks
the real threshold endpoints using $1800$ moments at $2000$ bits
and the conditional slope using $1200$ moments.
\nolinkurl{certify_critical_constants.py} encloses the critical
constants using $2000$ moments at $2600$ bits. Both checks retain
their acceptance tests under \texttt{python -O}. The numerical
phase illustration and finite-length examples are not certificates.
The README lists each script and its output.
