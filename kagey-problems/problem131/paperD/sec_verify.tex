\section{Verification}\label{sec:verify}

The proofs use three certified computations, apart from short exact
ratios such as those in Proposition~\ref{prop:dip-hyp}.
First, \texttt{certify\_elephant.py} encloses the 60-term sum in
Theorem~\ref{thm:erw-bounds}(b) in $[102.586396,102.586398]$.
With the analytic tail, it is below $102.59$, giving the constant $5200$.
Any finite bound suffices asymptotically, but this value determines
the explicit thresholds in Proposition~\ref{prop:dip-hyp} and the
second-order results. Second, the same script certifies the
Landau derivative and curvature enclosures of
Lemma~\ref{lem:landau-mode}. Lean checks these independently.

Third, \texttt{certify\_convex.py} brackets each crossing for
$10\le N\le2000$ and encloses the law throughout that bracket,
checking every possible mode and the required second differences
(Proposition~\ref{prop:convex-certified}).
The separate \texttt{certify\_center.py} proves
Proposition~\ref{prop:center-small} and the finite part of
Proposition~\ref{prop:dip-hyp}. For $5\le N\le9$, the stated
convexity and center checks are kernel-checked in Lean.
The outputs and rational witnesses are in
\nolinkurl{data/certify_convex_output_2026-10-17.txt},
\nolinkurl{data/certify_center_output_2026-10-17.txt},
\nolinkurl{data/witnesses_convex_2026-10-17.jsonl}, and
\nolinkurl{data/witnesses_center_2026-10-17.jsonl}.
The witnesses record script hashes and software versions.
Each certification script fails if a required check fails, and
range-based scripts also reject empty ranges.

The Lean~4.33.1 library in
\nolinkurl{kagey-problems/problem131/lean/PaperD} proves the finite
identities, crossing bounds, sign arguments and certificate checks.
The bulk and eventual-shape proofs use six named classical inputs,
namely Fourier inversion, the compound Poisson characteristic function,
Efron--Stein, Scheff\'e, unimodality of class-$L$ laws, and Hoeffding's
hypergeometric bound. Their sources and precise formal status are in
\nolinkurl{MAP.md} and \nolinkurl{coverage_tables.tex}.
The library uses Mathlib revision \texttt{0df444a360ea}; the recorded
kernel build reports only \texttt{propext}, \texttt{Classical.choice}
and \texttt{Quot.sound}. Generated certificate rows are checked with
exact outward-rounded integer arithmetic, without \texttt{native\_decide}.
This does not formalize the six classical inputs or
Conjecture~\ref{conj:convex}.

The separate Python runs used Python~3.14.3, python-flint~0.9.0
(FLINT~3.6.0, including Arb), mpmath~1.3.0, numpy~2.4.2 and scipy~1.17.1.
The figures, tables and other numerical illustrations are not proof
inputs. Further checks and rerun commands are documented in the
repository named under Code availability.
