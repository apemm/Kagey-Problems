# Removed proofs

Material cut from the Problem 131 papers while shortening them, kept for reference and in case a
referee asks for it. None of this is part of the current papers, and labels and cross-references
refer to the versions the material came from, so the files are not meant to be compiled as they
are.

- `B_removed_2026-09-26.tex` has the proofs and results removed from Paper B's appendix on
  2026-09-26, word for word. Its header says where each piece came from and what replaced it in
  the paper.
- `paperC_full_2026-09-26/` and `paperD_full_2026-09-26/` are Papers C and D as first written, at
  71 and 50 pages, before they were cut to their current length. They have the full proofs of the
  side results that are now remarks, and the longer explicit-constant proofs. The `.tex` files are
  the sources and the `.pdf` is the compiled version.

Earlier versions of Papers A and B are in the git history, for example in commit `cd600ca`.
