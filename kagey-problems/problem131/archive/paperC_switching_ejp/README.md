# Problem 131, Paper C: the earlier EJP version

Archived on October 24, 2026. Until that day Paper C was "Face selection for slowly switching
Markov chains", written in the class `ejpecp` for the Electronic Journal of Probability, with a
separate supplement. Following the plan of October 23 the paper was restructured for the Journal of
Theoretical Probability as "Occupation counts of rarely switching Markov chains: stratified local
laws, modal supports and reconstruction", in `../../paperC` with the main files
`problem131_chains.tex` and `problem131_chains_sn.tex`.

Files here:

- `problem131_switching.tex`: the earlier main file. It inputs the section files of `../../paperC`
  by relative name, and those files have been rewritten since, so it no longer rebuilds as it was.
- `problem131_switching.pdf`: the build of October 23, which is the record of that version.
- `supplement.tex` and `supplement.pdf`: the supplement of that version, which the current paper
  no longer has or points to.
- `sec_examples.tex`: the examples section of that version, which neither current main file inputs.

The check scripts, the ledgers under `data/` and the first draft of September 26 under
`removed_proofs/` stayed in `../../paperC`.
