# The exact value on seven by ten

The computer-assisted result is

\[
f(7,10)=18.
\]

The lower bound is explicit. The upper bound uses an analytical reduction to a complete finite family and an exhaustive ordering search. Together with `seven_nine_exact.md`, this establishes

\[
f(7,9)=17,\qquad f(7,10)=18.
\]

## An explicit lower bound

The following column word contains 18 black points:

\[
17,\quad7,\quad47,\quad67,\quad6,\quad6,\quad56,\quad345,\quad123,\quad7.
\]

Every entry lists black row numbers in one column. Both rectangle generators verify that all 1,385 rectangles have different white presentations. The witness is saved in `seven_ten_lower_witness.json` and regenerated by `seven_ten_lower_witness.py`.

## Complete classification of the 19-point candidates

Let \(z\) be the number of empty columns. The axis row-tree graph has

\[
e(H)=19-(10-z)=9+z.
\]

The individual-completion bound for a column with \(k\) black rows is

\[
e(H)\le6+\left\lfloor\frac{(7-k)^2}{4}\right\rfloor.
\]

A column of size at least four is impossible. If a triple exists, then \(e(H)\le10\). Equality forces the unique-triple boundary family: one triple, eight doubles, and any empty or singleton columns. The proof is in `large_column_boundary_classification.md`.

If \(z\ge2\), a triple is impossible since \(e(H)\ge11\). But at most \(10-z\) nonempty columns of size at most two contain fewer than 19 black points. Thus \(z\le1\).

If \(z=1\), a triple is necessary. The equality classification gives exactly one triple, eight doubles, and one empty column. There are 1,890 labeled column multisets of this form.

If \(z=0\), write \(t,d,s\) for the numbers of triple, double, and singleton columns. Then

\[
2t+d=9,\qquad s=t+1.
\]

Removing one singleton produces an axis-valid 18-point family on seven by nine. Conversely, adding any singleton to any such family produces an axis-valid 19-point family on seven by ten. Therefore the independently enumerated seven-by-nine family gives a complete enumeration here.

The exact counts before geometric reflection are:

| Triples | Doubles | Singletons | Empty columns | Column multisets |
|---:|---:|---:|---:|---:|
| 0 | 9 | 1 | 0 | \(12,670\cdot7=88,690\) |
| 1 | 7 | 2 | 0 | \(18,480\cdot28=517,440\) |
| 2 | 5 | 3 | 0 | \(3,780\cdot84=317,520\) |
| 1 | 8 | 0 | 1 | 1,890 |
| Total | | | | 925,540 |

There are no cases with three or more triples. Vertical reflection gives 463,006 representatives. Their full row-mask lists are stored in `seven_ten_19_data.json`.

## The exhaustive ordering check

`finite_column_order_search.js` uses the exact tilted-presentation and axis-rival tests described in `seven_nine_exact.md`. It supports the actual board width as a parameter. The only geometric reductions are vertical reflection of candidate multisets and horizontal reflection placing one fixed triple, when present, in the first half of the board. Repeated singleton columns are treated as indistinguishable. Row permutations are not used.

The full search was divided into two bounded runs:

| Run | Completed representative indices | Nodes, including any partial work | Seconds |
|---|---|---:|---:|
| First | 0 through 317,988 | 596,557,824 | 600.005 |
| Continuation | 317,989 through 463,005 | 190,425,014 | 218.739 |

The first run stopped partway through representative 317,989. The second run restarts that representative from its root. Every representative was therefore fully checked at least once, and none has a valid ordering.

The combined work was 786,982,838 nodes and 818.744 seconds. This proves that a valid 19-point board does not exist. Any larger valid blackout could be reduced to a valid 19-point blackout by restoring some black points to white, so the upper bound is 18.

`verify_seven_ten_coverage.py` checks every recorded representative index, verifies that the union of completed chunks is the full range, and rechecks the 18-point witness independently. Its summary includes hashes of the candidate list and both result files.

## A corrected preliminary check

A preliminary 20-point run initially covered only boards containing a triple. Ten-double-column triangle-free row graphs are also possible at that size. The builder was corrected before using that preliminary run as an upper-bound certificate. The corrected full family has 8,124 vertical-reflection representatives. It is also infeasible, with 9,732,734 search nodes in 8.054 seconds.

This preliminary 20-point result is redundant after the complete 19-point check. The omitted all-double cases never affected the 19-point candidate list, which includes all nine-double families with their singleton column.

## Reproduction

After generating the seven-by-nine families, run:

```text
python build_seven_ten_search.py 19
node finite_column_order_search.js seven_ten_19_data.json 600 0
node finite_column_order_search.js seven_ten_19_data.json 360 317989
python seven_ten_lower_witness.py
python verify_seven_ten_coverage.py
```

The restart index is part of this recorded run. If a different machine reaches its time cap at another index, restart at the last, incomplete index shown in its output and use the corresponding files in the coverage check.
