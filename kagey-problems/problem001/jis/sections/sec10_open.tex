\section{Open questions}\label{sec:open}

\begin{enumerate}[(1),leftmargin=*]
\item Find the rational series $\sum_{m\ge0}a_5(m)z^m$ (Theorem~\ref{thm:periodic},
Remark~\ref{rem:fivecounts}) and the growth rate of $a_5(m)$.
\item A valid $6\times9$ blackout of $16$ points passes the test of
Theorem~\ref{thm:collar} with seven columns black only in row $1$ on each side, as the script
\nolinkurl{six_row_collar_6x9_check.py} checks. With
Theorem~\ref{thm:sixrow} this gives $m+7\le f(6,m)\le m+8$ for $9\le m\le14$. Which
value holds?
\item Is $f(h,m)=m+q_h$ for all large $m$ when $h\ge7$? By Theorem~\ref{thm:collar}, one
valid $7\times m$ blackout of $m+12$ points passing the collar test would settle $h=7$.
\item Lemma~\ref{lem:girth} and Neuwirth's bound for bipartite graphs of girth
eight~\cite[Corollary~16]{neuwirth2001} give
$f(n,n)<n^{4/3}+\frac23n-\frac29n^{2/3}-\frac{20}{81}n^{1/3}$ for $n\ge3$, and
Theorem~\ref{thm:alteration} gives $f(n,n)\ge0.29\,n^{6/5}(1+\ln n)^{-2/5}$ for large $n$.
Lavrov~\cite{kageyMSE} used the same method for the triangular version. What is the true
order, and the least $n$ with $f(n,n)>2n$?
\end{enumerate}
