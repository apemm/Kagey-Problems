Let S be a valid blackout of the h x m grid with at least k points, and set each point variable true exactly when its point is in S. A clause of encoding A says that the inclusion-minimal symmetric difference D = A xor B of two distinct rectangles is not all black. If D were inside S, then A \ S = B \ S by the difference-set lemma (A minus S equals B minus S exactly when A xor B lies in S), so two rectangles would show the same points, against validity. So every such clause holds. At most n - k points are white, so at most K = n - k of the negated point literals are true, and setting the counter variable s(i,j) true exactly when at least j of the first i of them are true satisfies every counter clause. The first clauses say that a true literal starts or raises the count and that counts never fall, and the last clause of each step would fail only if K+1 of the literals were true. So the instance is satisfiable, and its unsatisfiability proves f(h,m) < k. For a split instance the first column of S agrees with exactly one sign pattern, so S satisfies that part (the base clauses plus its units). The parts run over all 2^h patterns of the first column, which the second generator checks, so if every part is unsatisfiable no such S exists. For the six-row instances, let m be one of the widths 8 to 14 and let S be a valid blackout of the 6 x m grid. The row bound (Theorem "row bound", m >= 3) gives |S| <= m + q_6 = m + 9, so it is enough to rule out |S| = m + 9. So let |S| = m + 9. A valid blackout is axis-valid, since validity asks that all rectangles show distinct sets and the axis-parallel ones are among them. The equality theorem (Theorem "equality structure") applies, since h = 6 >= 4 and m >= 3. It says that every column of S is a singleton or a double, that exactly nine columns are doubles with distinct row pairs, and that these nine pairs are the edges of K_3,3 for one partition of the six rows into two triples. These balanced 3+3 partitions are the ten ways to choose the triple that holds row 1, in rows one-based, {1,2,3}|{4,5,6} (p0), {1,2,4}|{3,5,6} (p1), {1,2,5}|{3,4,6} (p2), {1,2,6}|{3,4,5} (p3), {1,3,4}|{2,5,6} (p4), {1,3,5}|{2,4,6} (p5), {1,3,6}|{2,4,5} (p6), {1,4,5}|{2,3,6} (p7), {1,4,6}|{2,3,5} (p8), {1,5,6}|{2,3,4} (p9). Instance six_wM_pP is the instance of partition pP on width M. Give each column of S its type (its row if it is a singleton, its edge if it is a double). Then each column has exactly one type, the type variables agree with the points, and each edge type is used exactly once, which is the structure the structured encoding assumes. A pair clause says that the symmetric difference of two rectangles that share a corner is not all black, which holds by validity as above. Set the indicator of a tilted rectangle true exactly when its four corners are black. A valid blackout hides at most one rectangle (two hidden rectangles show the same empty set), so at most one indicator is true and the counter with K = 1 is satisfied. So S satisfies the instance of its partition. If all ten instances of width m are unsatisfiable, no valid blackout of m + 9 points exists on the 6 x m grid, and with the row bound f(6,m) <= m + 8. The certificates cover the CNF files only. The row bound and the equality theorem are proved in the paper by hand and are not part of them. Dropped clauses (those the structure makes true, and the pairs of two axis-parallel rectangles) only weaken the formula, so they cannot make it wrongly unsatisfiable.
